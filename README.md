# CalcTemp

Conversor de Temperatura em Java

Ooi,

Este e um projeto simples e prático desenvolvido em Java. Conceitos fundamentais da linguagem, como variáveis, constantes e operações.

Sobre o projeto: 

Variáveis -> double : os valores mudam de acordo com a temperatura inserida.

Constantes -> final : para valores fixos que não mudam como o 32 e 5/9.

O programa realiza a conversão de temperaturas de Fahrenheit (ºf) para celsius (ºC), utilizando uma fórmula matemática oficial:
C = (F - 32) * (5 / 9).

No código, terá a palavra fahrenheit sendo usada de duas formas, como:

double fahrenheit = 86, aqui eu estava declarando a variável, tipo avisando ao Java que ela já existe e dei um valor inicial.

fahrenheit = 150,e nesse aqui apenas reutilizei e mudei o valor dela, não era necessário ficar repetindo a mesma palavra "double", pois já indentifica o tipo dela.
